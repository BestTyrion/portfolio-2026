## Windows 11 啟動

1. 解壓到英文路徑，例如 D:\StellarNexus。請勿在ZIP預覽內直接執行。
2. 安裝Node.js 24 LTS；首次安裝完成後關閉並重開命令提示字元。
3. 雙擊START_WINDOWS.cmd。首次需要網絡下載套件、建置並建立本地資料庫，耗時取決於網絡。
4. 看到伺服器就緒後開 http://localhost:5173/ 。保留命令視窗。
5. 本地資料保存在.wrangler/state，與線上資料庫分開。關閉視窗再啟動仍會保留。

腳本不是exe，沒有聲稱已在Windows真機測試。遇錯誤請保留視窗中的錯誤文字。不要把整個資料夾刪除或刪除.wrangler，否則本地資料會丟失。

## 手動啟動（Windows/macOS/Linux）

需要Node.js 24及可用網絡：

```sh
npx --yes pnpm@11.25.0 install --frozen-lockfile
node scripts/local-setup.mjs
npm run dev
```

local-setup會設定portable profile、生產建置、依序套用尚未記錄的本地遷移。它不會重設資料庫。首次完成後可直接npm run dev。

## 檢查

node node_modules/typescript/bin/tsc --noEmit

## 已实现的关键操作

- 开场使用七色粒子星流，支持跳过；原生SVG星河Logo表达多位成员与经验汇流。
- 分类、搜索、多选、自建兴趣；同一主题可设想学、可教或两者；程度与地区、方式、时间持久保存。待审自建主题不公开。
- 图谱展示技能节点和有来源的主题关系；支持搜索、供需筛选、缩放和文字列表。角色用文字及外环，与七色分开。
- 群体活动可筛选、查看详情、报名与候补、取消与原子递补、活动码签到、反馈、组织者确认场地及完成活动。
- 活动成员读写共同笔记；组织者向公开分享技能的人发出站内共同带领邀请，对方接受后才加入教师表。
- 公共知识显示来源、条件和核对状态；可收藏，来源撤回后不再提供原文。导师档案需本人同意、人工核对后展示，可退出推荐。
- 我的星河可创建、修改、删除私人笔记和合集；逐份授予整理许可。仅处理本人选择的资料，保留原始来源；本人核对可编辑草稿。复习卡保留来源与答案，支持已掌握、仍不确定、需要再练。
- 时间线保留笔记、整理、复习、分享等实际记录。JSON导出仅包含本人资料。设置偏好、受邀响应、个人密码变更可持久保存。

## 美术与素材策略

七色：#E87878 / #E9A461 / #DDBB51 / #79AD82 / #58ADA9 / #639DD1 / #9A83C4。代表成员与经验的多样性，不绑定年龄、性别、固定角色。底色为轻暖白，主正文深蓝灰；颜色集中于品牌、星流和主题节点。

活动采用可比较的目标、时间、人数、场地与分享者信息。公共知识以照片、方法和出处呈现；私人工作区强调内容、来源与状态。减少大面积泛化渐变、装饰性占位图和统一空白卡片。

8张独立真实摄影：手机、多人协作、电子设备、陶艺、讨论空间、咖啡、吉他与福州街景。图片使用img与object-fit:cover，保留比例并裁切，不使用拼图背景定位；素材来源、摄影师及许可列在photo-credits.json。场地图片不代表真实合作，导师不使用素材人物冒充肖像。

参考方法：Meetup的活动决策信息、ClassBento的成果与工作过程、Instructables的步骤和条件表达。仅借鉴信息组织，不复制网站页面或品牌。图版以精确SVG输出，照片与说明配合展示理想线下服务。

## 技术与数据

React / TypeScript / Vinext + Cloudflare Worker + D1。schema.ts声明33张表；V2新增私人知识、收藏、复习、时间线、整理任务、导师、邀请、偏好、共同笔记、合集与图谱关系。0001为追加迁移，0000保持不变。持久记录位于D1，不把浏览器缓存当跨设备数据库。

API分为原有业务与/api/v2。登录使用HttpOnly Cookie。新增写入检查同源Origin；私有查询逐次检查owner_id。密码使用PBKDF2，变更需要当前密码，并撤销其他会话。共享演示角色只供私人演示，真实开放前应移除。

## AI实施与后续开发

当前已经实现整理任务、选源授权、可编辑输出、核对保存、来源复习卡与时间线，但内容处理为明确标示的範本演示，未接真实LLM。没有宣称已实现语义摘要、自动事实核验、录音转写或智能复习预测。

下一阶段的具体实施：
1. 真实模型：服务端密钥、可取消异步任务、逐份来源ID和引用片段、结构化输出校验、拒绝无来源断言、预算及失败重试。由成员选择来源与确认，不自动公开。
2. 上传与转写：R2存储授权文件、类型与大小限制、任务状态、录音的参与者同意与删除机制；目前不提供假上传按钮。
3. 地方文化趋势：累积按地区与主题的每日匿名聚合快照，报告样本量和时间窗；达到可比条件再展示变化，不将当前Demo供需等同城市整体趋势。
4. 正式服务：邮件验证、账号恢复、完整注销与保留策略、防滥用、细化审计、通知队列、可访问性人工测试、Windows真机验证及用户测试。
5. 场地：增补提供者审核、真实许可、库存锁与取消政策；当前人工确认和时段冲突检查不代表已向真实场地预订。
