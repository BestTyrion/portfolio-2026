# 线下共创站与难忘时刻纪念牌

## 交付
- 重写 exhibition.html，提供假设24㎡平面、四个可切换区域、75分钟共同开启流程、信息映射、文化产出及个人套件。
- 三幅AI概念渲染：空间、公共纸品与私人套件。明确不是真实场地或制造成果。
- offline/print.html：入口牌、参与卡、A6封面、A5信纸与试围腰封、35mm记忆牌尺寸样片。
- offline/fold.html：A3两面四联折页，展开420×148.5mm，折后约105×148.5mm。只有桌面纸样，无印厂出血；未实物打样。
- offline/host.html：物料、角色、服务执行表与异常处理。

## 纪念套件
册子＋信封（地图和信）＋一枚街角记忆牌。记忆牌正面拟用用户最难忘时刻经AI转绘、本人确认后制成的工艺线稿；背面刻加入批次与可选短句。批次不是购买次序，也不是个人排名。当前原型统一为 DEMO-B01 / 第01演示批次，正式社区批次分配待接入。

## App
在时间线每条记录、离开流程第3步和我的资料增加入口。成员选择自己的记忆，填写原因、风格、短句，确认流程说明。服务端保存记忆快照与演示批次，不采用客户端伪造批次；新确认替换旧方案，原日记/胶囊不变。未选择不阻止离开。旧成员缺少批次时使用明确标注的演示默认批次。

只保存转绘意向，不上传照片、不调用AI、不生成图案、不下单、不自动公开。当前参考照片不会冒充用户实际经历。私人方案不进入组织者响应，打印导出仅允许本人会话，HTML转义。JSON state扩展，无数据库迁移。

## 验证
30项领域/API测试（含纪念牌素材归属、说明确认、批次防篡改、快照、组织者隔离、私有导出与HTML转义）通过。浏览器验证选择保存与刷新保留、说明展开、打印方案、线下区域与流程切换、纸样显示。未进行实体制造、打印机套准、现场测量或用户研究。


## 本轮修订：编号时间胶囊封套
信封改为拟180×230×12mm侧褶厚纸封套，带封口、日期封条、入住批次、个人纪念编号、居住时间与开启日。新版产品图以第03批入住/B03-017为虚构示例，挂件展示虚构共创时刻的AI线稿概念；并非真实用户转绘成果。新版空间加入公开批次墙与右侧回看/选择/封存台，私人材料由本人带走。

App首次保存选择时分配随机演示个人编号，并在重新选择时保留；不代表成员顺序或真实登记号。纸本纪念册及方案导出显示同一编号。正式社区编号及实际AI转绘仍待运营接入。
