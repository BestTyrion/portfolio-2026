- 患者端：青绿色主题；医生端：深蓝色主题。
- 登录页和两端页面顶部均提供 English / 中文；每次重新打开或刷新时默认英文。

## Windows 使用

1. 完整解压压缩包到新文件夹。
2. 如旧版仍在运行，先关闭对应的 MEDMIND Node 服务（任务管理器中确认路径为旧 MEDMIND 文件夹的 node.exe），避免旧服务继续占用 3001 端口。
3. 双击 MEDMIND_Patient.exe 或 MEDMIND_Doctor.exe。
4. 登录前可切换语言；登录后可随时在顶部切换。

演示账号：
- 患者 Jason：jason@medmind.demo / jason-demo
- 患者 Chan：chan@medmind.demo / chan-demo
- 医生 Lee：lee@medmind.demo / lee-demo

如需迁移旧演示记录，先关闭旧服务，再把旧文件夹的 data 目录复制到新文件夹同名位置。
