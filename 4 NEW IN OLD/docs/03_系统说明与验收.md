# 系统说明与验收

## 技术与数据
React + Vinext；服务端 API；D1/SQLite 持久化。未用localStorage充当多用户数据库。
仅一个虚构成员林予安，组织者与成员是演示角色，不是正式多租户身份系统。当前私有站点仅供所有者演示。演示口令246810是公开测试值，不可作为正式工作人员认证。

## 信息架构
青年端：在这里生活（资料/疑问）→一起做点事（详情/报名/参与确认）→社区共创（提交/许可/公开内容）→我的这段日子（私人片段/选取/预览/导出/制作申请）→回来看看（周期/回看/近况）→准备离开（导出/许可/交接/结束）。
组织者：工作概览（待办/审计）→活动与资源→共创与授权→疑问与回应→制作与交接→服务设计档案。

## 实体关系与数据字典
- residents：id/name/stage/replay/next_replay/leaving/created。回看设置只对本人返回。
- resources：title/body/category/source/verified/status/owner。有来源、核实日与责任人。
- activities：title/kind/date/place/capacity/body/status/intensity/material。只管理示例活动。
- registrations：resident_id→residents；activity_id→activities；status/photo/created。报名并不等于合影或出席。
- entries：resident_id→residents；title/body/place/created。私人记录不返回组织者。
- assets：resident_id→residents；title/body/author；archive/display/commercial独立；status/version/created。
- cases：resident_id→residents；title/body/reply/status/created。
- orders：resident_id→residents；可关联asset_id→assets；product/status/created。
- handovers：resident_id→residents；title/status/assignee/created。
- audit：actor/action/target/created。记录操作，不记录私人日记正文。

主关系：居民一对多报名、记录、作品、请求、制作、交接；活动一对多报名；作品一对多关联制作；关键变化写审计。

## 状态规则
活动：开放→结束/取消，终态不直接重新开放。
报名：有名额→已报名；满额→候补；取消→释放名额并检查最早候补；活动结束→待确认参加→本人确认已参与。取消活动→报名同步标记。
内容：提交→组织者确认/退回；作者许可变化→版本+1、重新提交，公开页移除，关联未完成制作暂停。
请求：提交→处理中→等待本人确认→已解决或返回处理中；未解决关闭需要回应说明。
制作：申请→制作中→待领取→已领取；取消可结束；许可变化后暂停，仅能取消，恢复应重新申请。
交接：待接手→安排→成员确认交接完成；无人接手可中止。未处理完成前不允许完成搬离。
回看：关闭/月/季度/年；站内打开时判断到期；看过后安排下一次。无后台主动发送。

## 权限
组织者API不返回entries与replay/next_replay；仅看到选择提供的共创内容。
青年只能按固定演示成员操作自己的资料。组织者动作在服务端校验演示角色。正式部署给真实居民前必须增加独立账号、可信角色认证、成员隔离、访问审计与文件安全流程。

## 产出功能
- 本人选取的私人记录＋本人已公开共创内容→HTML纪念小册，可打印/PDF。
- 浏览器套装预览→封面、私人篇章、示意折页地图、封套，可打印。
- 已确认且允许公开内容→共创小志HTML；只授予公开不意味着可商业使用。
- 已确认且允许公开与文化产品内容→SVG明信片样稿。
- 参与工具→欢迎介绍、活动说明、共创任务、内容确认、组织者清单HTML。
- 个人数据→JSON下载。

## 已知边界
未接入真实居民、支付、照片/文件上传、复杂协同编辑、真实地图导航、实时消息、自动邮件短信、后台定时推送或人工回访。共创上传为文字；插画为概念矢量图。作品审核仅确认/退回，暂未实现逐段编辑评论；后台已支持发布新活动和资料。迁居支持限于资料导出，不声称迁入新社区仍有相同服务。
尚未真人研究和试点；没有孤独或社区关系改善的成效数据。日期按实际操作写入，叙事半年为虚构设定。
