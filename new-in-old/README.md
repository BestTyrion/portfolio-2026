# 新邻旧里 NEW IN OLD · V5 / 线下方案 V1

从切身之处，改善共同生活。

移动优先的服务设计与信息管理研究原型。包含独立演示成员、活动与组团、共同作品许可、私人时间线与地图、纪念册、时间胶囊、地点/活动/作品的后续、交接与离开。服务端通过浏览器会话隔离记录，使用 D1 持久化；不是正式的真实多用户社区服务。

V3更新：晴空男生版 / 橘光女生版、原创青春动漫与真实纸本手作照片、右上独立使用说明、日子双主入口、活动与本人胶囊收藏关注、自选胶囊关注范围。

## 体验路径

1. 从注册开始，输入虚构称呼，选择晴空男生版或橘光女生版。
2. “这里”认识生活入口；“一起”报名活动并设置参与偏好，创建小组。
3. “一起 → 一起留下”提交共创稿件，分别选择归档、展示、文化产品许可。
4. “我的”切换组织者演示，审核当前版本；再返回成员。
5. “日子”记录生活，时间线与足迹地图同步；选入纪念册后预览书册、地图折页与纸套。
6. 封存一个时间胶囊，选择日记与作品、打开日期，并给未来的自己写信。
7. 组织者可为同一地点、活动、作品添加变化草稿，注明来源、日期、前后状态，核对后发布；变化会汇到相关胶囊。
8. 可从作品发起交接，由组织者登记接续者同意，成员确认；没有接续者可中止。最后结束居住，日记与胶囊保留。
9. 在设置中开启每月、每季或每年回看，仅在下次打开App时检查提醒。

角色切换仅用于个人演示空间，不是真实管理权限。组团码不触发跨浏览器邀请。不要输入真实敏感资料；浏览器Cookie丢失后没有账户找回功能。

## 独立成果

- `/exhibition.html`：线下展览布局（4×6米假设空间）、分层实体地图概念、社区小志与版画、个人纪念套件；尚未制作实体与锁定场地。
- `/sitemap.html`：完整信息架构、成员旅程、公共文化产出与私人纪念的关系。
- `/credits.html`：真实照片、原创情境漫画与参考来源；福州照片来自三坊七巷，不冒充旗汛口现场。
- `/api/export`：本人纪念册、打开后的胶囊纪念册、已允许展示的社区小志，以及本人数据导出。HTML 提供浏览器打印 / 保存PDF入口。
- `docs/05_V2时间胶囊与服务闭环.md`：当前实现、数据关系与限制。
- `docs/06_V2验证记录.md`：自动化与界面验证证据。

`docs/01`—`04`、旧版静态样稿与 `tests/api_journey.py` 为 V1 历史材料，不能作为V2当前实现说明。共享林予安API已关闭（410）；迁移历史保留。

## 技术与本地检查

Vinext / React / TypeScript / Cloudflare D1。`lib/community-v2.ts` 为业务状态与验证，`app/api/life` 负责会话读写与乐观修订检查。当前数据采用每会话JSON状态，实体使用稳定ID关联；正式运营还需规范化关系模型、真实账户与跨成员授权。

Node.js 24 可运行：

```sh
node --experimental-strip-types --test tests/v2-domain.test.ts tests/v2-api.test.ts
node node_modules/typescript/bin/tsc --noEmit
npm run build
```

API测试使用内存 SQLite 与 D1 适配模拟，直接调用实际路由，覆盖隔离、来源校验、修订冲突与导出；不是托管环境负载或真实多用户试验。

本地数据库与在线数据库分离。首次安装依赖并构建后，依次应用 `drizzle` 内未执行的SQL至本地D1，再启动 `npm run dev`。不要重复运行已执行的迁移。托管发布按Sites流程自动应用新迁移。

## 未实现与研究边界

没有原生安装包、个人照片上传、精确定位、真实支付、即时群聊或外部消息推送；实体纸材、场地与装订尚未打样。公开文化产出需真实作者与合作方逐项确认。已经导出或印刷的内容无法远程撤回。

人物、活动、价格与发展记录均为设计情境，没有实地访谈或真实运营成效。需要后续研究验证成员需求、持续维护责任、接续流程和实体可用性。
