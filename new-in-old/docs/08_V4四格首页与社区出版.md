# V4 四格首页与社区出版

注册页和成员首页使用四格：初来这里、一起做事、留下这一页、后来再打开。透明原创简笔人物与有出处的真实照片分层显示，照片等比 cover，人物用 4×2 等比例精灵图；不再拉伸三联图。男生版与女生版切换主角，功能相同，可自由选择。

新增社区胶囊说明弹层、community.html 第01期概念样张、线下提示牌及真实编码二维码。入口接回 App 稿件许可和关注后续。已注册成员深链接直接打开弹层；新成员注册后继续。个人封存胶囊与社区公开内容分开，未添加自动公开或真实出版任务。社区按季度开启仍是拟议流程，尚无排期、真实刊物或物理场地。

照片仍为三坊七巷及手作参考，不冒充旗汛口实拍或地点前后变化。人物为原创AI插画。

验证：TypeScript、25项既有领域与API测试通过；浏览器核对男版、女版四格切换和社区入口。
