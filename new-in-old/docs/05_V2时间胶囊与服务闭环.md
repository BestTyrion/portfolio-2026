# 新邻旧里 V2：移动 App、时间胶囊与线下产出

2026-10-27。V2 取代 V1 的共享林予安演示账户。以下为实现范围，不是用户研究结果。

## 核心成果

- 一个移动优先的可操作 Web App，四入口：这里、一起、日子、我的。桌面以手机框展示。
- 先注册独立演示成员，再参与活动、组团、共创、记录、制册、封存、交接与离开。
- 地点、活动、作品以稳定编号关联；日记时间线与足迹地图读取同一份记录。
- 时间胶囊：固定快照（所选日记、作品版本、信、地点与报名活动）+ 独立后续（地点、活动、作品变化，含来源、日期、前序关系与接续署名）。
- 个人纪念册：HTML预览及浏览器打印入口，含足迹折页和纸套概念；未验证实际纸材与装订。
- 公共文化产出：已审核且允许展示的共创稿件可排成社区小志。概念版画、明信片另行展示，不构成真实生产授权。
- 线下展览：独立 `/exhibition.html`，4×6米借用房间的假设布局与可叠时间层的实体模型概念。具体地址和许可待实地确认。
- 完整信息架构 `/sitemap.html`，来源说明 `/credits.html`。

## 服务与信息管理的对应

| 服务节点 | 记录与控制 | 回到成员的价值 |
|---|---|---|
| 安顿/参与 | 生活资料来源与待核验标记；活动要求、费用、照片偏好、报名取消 | 知道怎样开始，提前知道现场安排 |
| 组团 | 活动关联、小组人数、成员、组团码、退出/解散 | 围绕具体事情一起参与 |
| 共创 | 作者、地点、版本、归档/展示/产品许可、审核状态 | 贡献被署名，使用范围自己决定 |
| 记忆 | 日期、地点、私人内容；同源时间线与地图 | 保留自己的生活细节 |
| 封存 | 独立快照与约定日期，可提前打开/删除 | 回看当时选定的版本 |
| 后续 | 对象编号、变化类型、来源、发生日期、草稿/发布、前序记录、同意署名的接续者 | 看见具体事物怎样继续变化 |
| 离开 | 交接待安排/待确认/已确认/中止，结束后取消报名 | 带走记忆，交代参与过的事情 |

## 技术与权限边界

`demo_sessions` 用随机 UUID HttpOnly Cookie 隔离每位浏览器访客，在 D1 保存 JSON 状态与修订号。写入使用条件修订号检查，防止多页面丢失更新。业务对象有稳定 ID，关系与业务校验在 `lib/community-v2.ts`；当前并非面向真实多用户运营的标准化关系数据库。

`/api/life` 仅按当前会话读写。组织者模式是同一会话内的角色演示，不是真实认证与授权。返回组织者数据时隐藏私人日记和胶囊；V1 共享数据的 `/api/community`、`/api/session` 已停用（410），旧导出被会话导出取代。

重要状态：许可更新会递增作品版本并暂停公开状态；旧版本变化草稿不能在新版发布后被沿用发布。接续者署名需勾选已同意，原成员还要确认交接。未完成交接会阻止结束居住；可选择中止。封存快照不被日记删除或许可更新改写；删除胶囊才删除该副本。已导出/印刷内容无法远程撤回。

当前组团只在独立演示空间运行，组团码不会触发跨浏览器邀请或联系真实成员；未提供群聊。定期回看仅在再次打开App时检查到期，不发送外部消息。没有精确定位、个人照片上传、支付或真实活动名额管理。真实用户上线需要身份系统、跨成员服务、标准化数据模型、权限与审计、生命周期及备份策略、实际社区责任人和试点研究。

## 视觉与素材

街巷青与晚霞粉由成员主动选择；配大字、减少动画、夜间回看安静设置。真实照片来自 Wikimedia Commons（福州三坊七巷，非旗汛口）和 Pexels，来源在 `public/credits.html`。原创生成漫画描述到达、共创、离开后回看，不作为真实调研摄影。用户给出的实体模型仅作表达参考，没有挪用为本项目成果。
