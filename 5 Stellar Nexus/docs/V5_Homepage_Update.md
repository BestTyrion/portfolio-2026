# V5 · 星球主页与知识星河入口

访问顺序：首页 → 点击「进入知识星河」→ 粒子星河 → 选择兴趣 → 我想学／我可以教 → 进入平台。

首页每次重新打开都显示，不再受旧版 sessionStorage 跳过逻辑影响。主页主导航中的「知识星河」与主按钮进入同一星河入口；其他导航可直接访问相应模块。第二层点击品牌返回首页。语言切换沿用设备偏好。

视觉参考：用户提供的 SpaceX 官网截图及 https://www.spacex.com/ 。仅参考深色全屏、巨大标题、星球构图和细边框按钮；保留星河交汇品牌与独立内容。

火星图片：NASA/JPL-Caltech，Mars Planet Globe；https://science.nasa.gov/resource/mars-planet-globe/ 。下载后保存 public/space/mars.jpg，通过 CSS 降低饱和度并叠加光照遮罩。
